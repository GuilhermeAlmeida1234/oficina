# oficina3
# 🚗 Oficina Mecânica - Website

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **site para uma oficina mecânica**, com o objetivo de apresentar os serviços oferecidos, informações da empresa e facilitar o contato com clientes.

O foco do projeto está na construção de uma interface simples, organizada e responsiva, utilizando apenas tecnologias fundamentais da web.

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3

---

## 🎯 Funcionalidades

* Página inicial com apresentação da oficina
* Seção de serviços oferecidos
* Página "Sobre Nós"
* Página de contato
* Menu de navegação com dropdown (apenas com CSS)
* Layout responsivo
